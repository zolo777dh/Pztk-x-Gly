Naowh Defensive Planner runtime, data validation, display and desktop PZTK1 format are independently implemented for this application. No NSR or NSRT runtime is required or bundled.

Third-party runtime libraries are redistributed with their existing notices:
- LibStub (public domain)
- LibSerialize (MIT, Ross Nichols)
- LibDeflate (its full LICENSE is included)
- CallbackHandler-1.0, LibCustomGlow-1.0, LibGetFrame-1.0 (embedded notices / license files retained)
Library snapshots originate from the user's supplied complete addon archive. Spoken cues use the game's own text-to-speech, and alert sounds are the game's built-in sound files referenced by ID; no third-party audio is bundled. No strategy article text or NSRT encounter implementation is bundled.

The 0.3.0 in-game editor, controls, scoped-set model, bounded CBOR import adapter
and original layout are implemented in this project. The bundled Catalog.lua is
factual reference data generated from the existing source snapshots, not provider
logic or a copied NSR/NSRT interface. Game icons/fonts are resolved by the client.

Fonts: URW Gothic Book and Demi (Media/Fonts) are from URW++ base35 fonts, licensed
under the AGPL with the font exception; see Media/Fonts/URWGothic-LICENSE.txt. The
commercial Naowh / ITC Avant Garde Gothic font is not included.
Media/UI textures (rounded corners, icon mask, interface glyphs) were drawn for this
addon by tools/bake-addon-media.mjs.
