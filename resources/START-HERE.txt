Pztk x Glyalith 0.6.0 — Windows x64

Extract the complete ZIP into a normal folder and launch Pztk x Glyalith.exe.
Do not run the exe directly inside the ZIP. Node.js is not required.


PUZATIK REMINDERS — IN-GAME WORKSPACE (0.3.0)
The bundle includes PztkReminders-0.3.0.zip. Replace Interface/AddOns/PztkReminders
with its folder while WoW is closed. Keep PztkRemindersDB SavedVariables.
The displayed name is Puzatik Reminders. Disable NSR / NSRT / TimelineReminders
while using this separate reminder engine.

Open /puzatik or /pztkr. Create defensive sets separately under Mythic+ and Raids.
Choose spec -> dungeon/raid -> NPC/boss -> ability -> defensive set. Raid reminders
also support time from pull / phase, recipients and display actions. Save explicitly.
A defensive callout shows the selected defensive icon(s) and text. Together groups
and priority order are editable. Test previews the display; verify triggers in game.

Profiles manages creation, copies, rename/delete, selection and PZTK1 import/export.
Direct NSRPACK2 and full current NSRT Profile/EncounterAlert imports are supported
with review reports. Licensed NSR packs stay managed in NSR. Source strings remain
local. One native PZTK1 string combines configured M+ and raid content.
Old shared presets split into independent copies on first editor save.
The desktop preserves both collections and imports HTML/JSON into chosen content.
Use the in-game set editor for scoped profiles; legacy NSR editors are compatibility
tools over the original shared source data.

Retail 12.1.5.70448 / Forever 1.60.1.70425 targets remain unchanged. The bundled
catalog is Retail-only. Forever supports manual/imported IDs. BigWigs/LittleWigs,
DBM and ExBoss are separate providers. No live game test was available. Public
readiness is used; inaccessible charge counts are not guessed. Fixed spell-icon
reminders can be configured without readiness selection. /pztkr debug prepares
a copyable provider report for BugSack troubleshooting. Read addon INSTALL.txt.

ADDONS AND DIAGNOSTICS
Choose Retail or Forever before working. Add the base addon and module folders
with +, or select their common parent directory. Multiple folders can be added
and selected together. Scan checks every selected addon under the selected client.
Ctrl+A, Ctrl+click, Shift+click and Shift+drag support multiple folder selection.
Right-click Refresh updates the source listing. Delete folder removes the entry
from the application list; it does not delete your addon from disk.
Ctrl+F searches the open source; Ctrl+Shift+F searches connected addon folders.
Import BugSack / BugGrabber reads exported errors / SavedVariables. It does not
read the live game process. Save game data with /reload, logout or exit first.
The Addons list starts empty each launch. Reconnect the same folders to continue
saved tasks. Task history, profiles, settings and backups remain saved locally.

AI WORKSPACE
1. Select your addon projects, open AI Workspace and describe an error or feature.
   Diagnostics can open a task with the selected file and runtime error context.
2. Prepare context. Review the Context tab: build, source excerpts, loaders,
   lexical symbol matches and the complete request. No request is sent yet.
3. Browser mode: open Browser panel, select ChatGPT or Claude and Open inside app.
   Sign in normally. Copy request, paste it into the website, then copy the JSON
   reply into Import JSON reply. Load reply also accepts a .json / .txt file.
   An external browser is available if the provider rejects embedded login.
4. Local / Cloud API: configure an endpoint, model and any API key in Settings.
   Load available models and Save Settings. Send reviewed request sends the
   prepared request to that endpoint. Cloud API billing is separate from a
   ChatGPT / Claude website subscription. API keys are session-only.
5. Validate reply, inspect Changes and select files to accept. Backup & apply
   verifies a ZIP backup before writing. Validate task projects rescans the code.
6. Restore task backup can restore original files if no later edits conflict.
   New files are removed by recovery only when their contents still match.

The assistant can propose changes across selected modules and create Lua / TOC /
XML files in existing directories. It cannot delete files or create directories.
Exact anchors and source hashes prevent applying an answer to changed code.
Lua syntax checks do not verify every game API or guarantee behavior in combat.
Website mode uses manual prompt / response transfer; it does not automate your
subscription or provide API access through the website account.

NSR: DEFENSIVE PLANNER / RAID PLANNER
Choose specialization by name (all 40 supported), then import an NSRPACK2 profile
or an HTML / JSON reference containing defensive sets. Create sets manually if
preferred. The importer reads the document's supported data / tables, not its name.
M+: choose dungeon -> NPC / boss -> ability -> defensive set.
Raid: choose season and Heroic / Mythic -> boss -> ability -> defensive set.
Assignments save locally. Both tabs edit ONE NSR profile. Export NSR creates one
string containing the configured M+, trash and raid rules for all configured specs.
Copy the string into Naowh Smart Reminders inside the game and verify triggers.
Trash needs NSR's ExBoss integration. A catalog entry cannot create a missing timer.
Account-licensed packs must be managed in the addon; licenses are not bypassed.

NSRT: NATIVE RAID PROFILES
Raid Planner -> NSRT profiles imports current !NSRT:Profile: or full
!NSRT:EncounterAlert: exports. Create / edit reminders, encounter IDs, Heroic /
Mythic difficulty, defensive icon / mechanic IDs, text, spec and phase-relative times.
Blank specialization preserves imported load filters. Explicit spec restricts them.
Restore previous version restores the preceding locally saved profile revision.
Single / group alert exports can roundtrip but require a full alerts export for
visual editing. The supported codec is the current CBOR / Deflate format.

Build NSRT profile uses shared NSR raid assignments and factual source schedules.
Choose a new profile or a copy of an existing NSRT profile. Review the generation
summary and skipped assignments, edit times if required, then Export NSRT profile.
NSRT shows the assigned set as text with its first spell icon. It does not implement
NSR's cooldown-based priority selection. NSRT may ask you to confirm shared raid
data during import. Import the string in NSRT and test it in game.

CLIENT AND DATA LIMITS
Retail target: 12.1.5.70448. Forever target: 1.60.1.70425.
NSR and NSRT workspaces are separated by client. The bundled eight M+ dungeons
and 20 raid bosses are Retail Midnight reference data. For Forever, use imported
or manually configured encounters and verify the installed addon's compatibility.
The app does not install profiles into live game memory, press abilities, publish
addon source edits to GitHub, or remove addon licensing. WCL / BGMT parsing and
real defensive-press timing averages are not included in this version.

NSR MIGRATION REVIEW (0.5.0 / addon 0.2.0)
Export complete profile shows grouped issues with spec and rule IDs. Save the full
migration report for review. Open editable migrated copy preserves the original
source and opens native reminders: edit defensive set, occurrence condition and
delay, then save and export again. Unsupported trigger conditions are not guessed.
Missing set references need review. ExBoss's empty-text active-set fallback remains.
cdmGlow, coveredSkip, coveredSkipDefaultOn and coveredCastWindow are retained but
not implemented. Do not treat a successful decode as full behavioral equivalence.
Native aura sounds require C_UnitAuras.AddAuraSound. /pztkr debug reports missing
APIs and pending/failed registrations. Registration changes wait for restrictions
to end. Private racial clips stay muted when readiness is unknown or inaccessible.
