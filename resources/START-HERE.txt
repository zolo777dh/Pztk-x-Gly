Pztk x Glyalith 0.1.0 — Windows x64

1. Распакуйте ВЕСЬ архив в отдельную папку.
2. Запустите «Pztk x Glyalith.exe». Не переносите EXE отдельно от ресурсов и DLL.
3. Нажмите «Open disposable demo», чтобы проверить интерфейс на безопасном примере.
4. Кнопка + возле Addons подключает папку аддона с файлом .toc.
5. Выберите Retail или Forever, нажмите Scan Project.

Патчи: Patch Assistant → Validate & preview → Create Backup & Apply.
Перед записью создаётся и проверяется ZIP. Откат: Project Tools → Restore.
Бэкап содержит исходники; это не копия всей игры или папки WTF.

Заметки: Encounter Notes. Сравнение логов и импорт файлов: Encounter Lab.
Поддерживаются структурированный HTML/JSON и таблицы HTML/CSV с сопоставлением столбцов.
Среднее считается по выбранным наблюдениям; рекомендации и реальные нажатия различаются.

ИИ: задайте локальную OpenAI-compatible модель (например, Ollama) или облачный API в Settings.
Модель не включена в архив. Ключи действуют только до закрытия приложения.
Warcraft Logs: нужен собственный API access token. Без него работают импорт файлов и кэш.

Это первая тестовая версия, без цифровой подписи. Работу EXE на Windows и аддонов внутри игры
нужно проверить на вашей машине. Полного каталога WoW API и автоматической проверки поведения
в игре пока нет. Подробности — resources/app/README.md.
