Pztk x Glyalith 0.2.0 — Windows x64

Распакуйте архив целиком в обычную папку и запустите Pztk x Glyalith.exe.
Не запускайте exe прямо из ZIP. Node.js и среда разработки не требуются.

DEFENSIVE PLANNER / RAID PLANNER
1. Выберите специализацию по названию (доступны все 40).
2. Import profile / HTML: загрузите NSRPACK2 или HTML/JSON с наборами защит.
   HTML импортируется для выбранной специализации независимо от имени файла.
   Поддерживаются структурированные presets и статические таблицы наборов со spell ID.
3. Для М+ выберите одно из восьми подземелий, НИП/босса и его способность.
   Для рейда выберите сезон и Heroic / Mythic, затем босса и способность.
4. Выберите набор защит. Назначение автоматически сохраняется локально.
5. Export NSR создаёт одну строку с М+, рейдом и всеми настроенными специализациями.
   Импортируйте её в Naowh Smart Reminders и проверьте поведение в игре.

Обе вкладки редактируют ОДИН профиль. Наборы защит доступны в обеих вкладках.
Heroic / Mythic фильтрует список механик; одинаковый spell ID использует общее назначение.
Для М+ доступны только способности сезонного каталога Эпохальный+.
Реальные времена нажатий и парсер логов не нужны.
Edit defensive sets открывает редактор: название, порядок, spell ID и Together.
Рабочие профили и исходные строки сохраняются отдельно; профили переживают перезапуск.
База рейдов взята из присланного NorthernSkyRaidTools: только ID, названия и принадлежность
к сложности, без Lua-кода и времён. Подтверждённые различия ID/ключей NSR учитываются.
Наличие способности в справочнике не создаёт отсутствующее событие в boss-mod.
Для треша нужны ExBoss и подходящие таймеры; карта и spell ID сохраняются отдельно от NPC.

БРАУЗЕРНЫЙ ПОМОЩНИК — БЕЗ API-КЛЮЧА
Diagnostics / Patch Assistant → Browser → Analyze selected file.
Или Describe a feature → Browser → Prepare browser request.
Просмотрите контекст → Copy request → Open ChatGPT / Open Claude → вставьте запрос.
Вернитесь в приложение: вставьте JSON-ответ или загрузите файл ответа.
Validate & preview reply проверяет Lua и показывает изменения.
Create Backup & Apply создаёт проверенный ZIP-бэкап и применяет патч.
Если исходный код изменился после подготовки запроса, подготовьте новый запрос.
Используется обычный аккаунт в браузере и его лимиты; обмен запросом/ответом ручной.
Settings позволяет выбрать Browser, Local API либо Cloud API.
Подписка ChatGPT/Claude и оплата API — разные услуги; Browser не требует API.

ДИАГНОСТИКА И ФАЙЛЫ
Addons → +: выберите несколько папок или общую папку NaowhForever и модулей.
Ctrl+A, Ctrl+ЛКМ, Shift+ЛКМ и Shift+перетаскивание выделяют несколько папок.
Scan сканирует выделенные папки под выбранный профиль Retail / Forever.
ПКМ → Refresh / Delete folder: обновление либо удаление только из списка.
После перезапуска список Addons пустой; рабочие профили и бэкапы сохраняются.
Ctrl+F ищет в открытом файле; Ctrl+Shift+F — по подключённым папкам.
Import BugSack / BugGrabber читает сохранённые ошибки, а не память процесса игры.
Перед записью исходников всегда создаётся бэкап; поведение проверяется вами внутри WoW.
Изменения локальных аддонов автоматически в GitHub не отправляются.
