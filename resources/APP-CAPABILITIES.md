# Pztk x Glyalith 0.6.2 + Naowh Defensive Planner 0.3.2

Pztk x Glyalith is a Windows desktop app for planning profiles for **Naowh Defensive Planner**, a separate WoW addon that combines defensive priorities, raid assignments and timed encounter reminders. Addon maintenance and AI tools remain in the same desktop application.

- **In-game workspace:** `/ndp` opens the window laid out like the design mockup: Overview, Mythic+, Raids, Defensives, Timeline, raid sections, Display, Profiles, Settings and Diagnostics. Only the current specialization is shown and edited. Create and edit content-specific sets and mechanic / pull / phase reminders directly in WoW. Each reminder is one card (When / Who / Show) with a live preview; search and reminder counts help find encounters. The window is static, with no animations. Reminders show spell icons and spoken spell names (NSR style) and glow the called spell on the Cooldown Manager or action bars. Each ability has its own screen text, spoken phrase or sound. Raid pages: shared/personal notes with group sync and assignments, a list of all boss alerts, debuff sounds with bundled Stoneform/Shadowmeld lists, raid tools (pull, break, invites, arrange, assistants), nicknames and a version check.
- **Persistent editing:** switching pages, encounters, difficulty, specialization or profiles keeps unfinished inputs and navigation state. Drafts survive close and logout/reload in local SavedVariables; explicit Save activates a change. Drafts are separate from runtime profiles and are not included in exports.
- **Independent content sets:** M+ and raid priorities are separate for every spec, with Together and disabled abilities. The first save copies legacy shared sets into independent collections.
- **Direct in-game migration:** unlicensed NSRPACK2 and current NSRT Profile / EncounterAlert exports (full, single alert or group, including raid-frame glows and pre-pull countdown times) can be imported with a review report. Source strings and reports stay locally in SavedVariables. Native PZTK1 combines the configured content.
- **One native export:** PZTK1 contains configured defensive sets, Mythic+ / raid mechanic bindings and scheduled assignments. Import it in Naowh Defensive Planner with `/pztkr`.
- **In-game diagnostics:** `/ndp diag` prepares a copyable client, build, provider-version and connection report for troubleshooting alongside BugSack errors.
- **Reminder model:** time, phase, ability timer or mechanic message → specialization, role, player or everyone → spell icon, text, sound or player-frame glow. Bar/countdown, circle and TTS displays are also supported.
- **Native migration editing:** NSR custom defensive reminders retain their specialization, priority set, counter condition and delay. Open an editable migrated copy from the export review; the original source remains available. Migration issues are grouped and identify the source rule and specialization.
- **Aura sound rules:** native client registrations, scoped to spec/map/instance; private Stoneform/Shadowmeld cues follow public readiness. Missing APIs or restricted changes are reported. No aura contents are read.
- **Timeline planning:** inspect reminders and drag markers to prepare new times, then save explicitly.
- **Defensive planning:** all 40 specializations, shared M+ / Raid set editors, and supported HTML/JSON imports. Public spell readiness selects available priorities / Together groups; inaccessible cooldown data is not guessed.
- **Migration:** existing NSRPACK2 working profiles and supported current NSRT Profile and EncounterAlert schedules (full, single-alert and group exports), including raid-frame glows and pre-pull countdown times; warnings, skipped entries and original NSRT strings are retained for review. Unsupported source sections remain in the desktop working copy. TimelineReminders export strings require a confirmed format/sample and are not advertised as decoded.
- **Two clients:** Retail 12.1.5.70448 and Forever 1.60.1.70425, with separate profile workspaces. Retail catalogs use the supplied Midnight S1/S2 reference snapshot: eight M+ dungeons and 20 raid bosses. Forever uses imported/manual encounters.
- **Addon maintenance:** multiple folders, batch scans, refresh and source search. Removing an entry never deletes files. Diagnostics cover Lua syntax, TOC/XML load references, interface declarations and Retail API migration checks generated from Blizzard's 12.1.5 UI source (removed and deprecated functions, removed events, combat log lockout, secret values, messaging lockdown); BugSack/BugGrabber imports are supported.
- **Optional AI:** selected-module context, saved conversations, local/cloud APIs and a ChatGPT/Claude website panel with manual transfer. Cloud requests send reviewed source/error context; website subscriptions and API billing are separate.
- **Reviewed source changes:** per-file diffs, syntax validation, verified backups, stale-source protection and restoration. Tasks, profiles and backups are local; API keys are session-only. Addons starts empty each launch.

The separate addon has its own runtime, displays, SavedVariables and PZTK1 import/export. It pauses live reminders when NSR, NSRT or TimelineReminders is loaded, preventing competing engines. It does not modify or uninstall those addons. Boss timers and phases need matching provider events; ExBoss supplies trash timers. Glows require supported visible frames. No live game or authenticated assistant website session was tested in the build environment.

See [START-HERE.txt](START-HERE.txt) and the included addon INSTALL.txt for installation.

Migration does not implement cdmGlow or coveredSkip / coveredSkipDefaultOn / coveredCastWindow behavior. These values are retained and flagged, as are missing preset references. Native aura registration depends on the installed client API; it is not guaranteed on Forever. The in-game editor and scoped sets require Naowh Defensive Planner 0.3.0. The folder and SavedVariables name remain NaowhDefensivePlanner / NaowhDefensivePlannerDB.
