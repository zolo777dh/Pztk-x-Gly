Pztk x Glyalith 0.1.11 — Windows x64

- Упрощён Defensive planner: специализация → подземелье → НИП/босс → способность → набор защит. Назначения сохраняются автоматически, Export NSR выдаёт готовую строку. Все 40 специализаций доступны по названиям.
- Убраны из основного сценария сопоставление столбцов, многочисленные кнопки и технические формы. Расширенные функции доступны в свёрнутом Advanced tools.
- Исправлен импорт числовых spell ID, объектов/словарей наборов и обычных HTML-таблиц защит. Обработка не привязана к формату Holy Paladin. Для нераспознанной таблицы показывается понятное объяснение; названия без spell ID не превращаются в выдуманные способности.
- Способности и timer ID ограничены НИП выбранного подземелья, проверяются перед записью. У spell ID нет числовых стрелок.
- Diagnostics сканирует все выделенные аддоны под выбранной версией игры, объединяет результаты и открывает нужный проект по ошибке.
- WCL runs & results очищается при запуске. Файлы результатов и ключи сохраняются.
- Пройдены 85 тестов ядра с реальным NSR и Lua 5.1; импорт, назначение и общий экспорт проверены через интерфейс для всех 40 специализаций. Также проверены босс/треш и пакетное сканирование под Forever.

Закройте приложение, распакуйте весь ZIP в новую папку и запустите Pztk x Glyalith.exe. Номер версии — 0.1.11. Срабатывания напоминаний проверяются в игре; треш требует ExBoss.
