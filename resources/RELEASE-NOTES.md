Pztk x Glyalith 0.1.7 — Windows x64

- Ctrl+F: поиск по текущему редактору с навигацией, регистром и целыми словами.
- Ctrl+Shift+F: поиск текста по всем подключённым папкам Addons. Переход открывает файл и совпадение, сохраняя незаписанные черновики в памяти.
- WCL → Defensive profile planner: импорт профиля NSR → разбор наборов специализаций → выбор механик подземелий → таблицы/записанные касты → средние и приоритеты → просмотр изменений → новая строка NSRPACK2.
- Оригинальный профиль и прочие настройки сохранены. Поддержаны боссы и треш по схеме предоставленного NSR; экспорт принят штатным DecodePack и реальным валидатором правил треша. Числовые Lua-ключи сохраняются.
- HTML/CSV/JSON, сопоставление столбцов, несколько подземелий и специализаций, исключение повторов, разделение сложностей/сборок и средние по реальным нажатиям. HTML с рекомендациями не превращается в выдуманные времена защит.

Распакуйте весь ZIP в новую папку и запустите Pztk x Glyalith.exe. Данные приложения и исходные профили остаются в пользовательском каталоге. Это наблюдаемые приоритеты, не автоматические нажатия и не доказанная оптимальная ротация. NSR хранит одно время на способность/набор; подробные средние остаются в анализе. Треш требует штатного таймер-провайдера ExBoss. Работу внутри игры проверяет пользователь. Подробнее: CHANGELOG.md, README.md и VALIDATION.md.
