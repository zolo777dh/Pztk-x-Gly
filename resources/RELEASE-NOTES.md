Pztk x Glyalith 0.1.8 — Windows x64

- Исправлена ошибочная блокировка «Re-sharing licensed or derived packs is not supported» для обычных паков с derivedFrom.
- derivedFrom — отметка исходного пака и автора, которую сам NSR использует для передачи доработок куратору. Она сохраняется при импорте/экспорте через Defensive profile planner и при переносе поддерживаемых напоминаний в редактируемый план.
- Планировщик показывает исходное авторство. Паки с лицензией аккаунта :LIC1: по-прежнему проверяются самим NSR; лицензии не удаляются.
- Пройдены 67 тестов, включая экспорт производных профилей и их проверку неизменённым декодером NSR под Lua 5.1.

Распакуйте весь ZIP в новую папку и запустите Pztk x Glyalith.exe. Настройки и сохранённые данные приложения остаются в каталоге пользователя. Повторите импорт исходной строки профиля. Подробнее: CHANGELOG.md и VALIDATION.md.
