Pztk x Glyalith 0.1.9 — Windows x64

- Исправлено отображение v0.1.6 в новых версиях приложения. Интерфейс теперь получает номер из package.json запущенной сборки.
- Убрана отдельная жёстко заданная версия в сервисе. Версия ZIP/EXE и версия верхней строки используют одни метаданные.
- В тест запуска упакованного приложения добавлено сравнение версии Electron, ответа сервиса и видимой строки.
- Все функции 0.1.8 сохранены, включая импорт производных NSR-профилей с сохранением авторства.

Закройте приложение, распакуйте весь ZIP в новую папку и запустите Pztk x Glyalith.exe из неё. В верхней строке должно быть v0.1.9. Данные приложения сохраняются в каталоге пользователя.
