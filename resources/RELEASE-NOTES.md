Pztk x Glyalith 0.1.10 — Windows x64

- Визуальный NSR Profile Editor: импорт или создание пустого профиля, наборы защит для всех классов/специализаций, энкаунтеры, spell ID и правила треша, /Export profile в NSRPACK2. Исходные данные, авторство и другие разделы профиля сохраняются.
- NPC & ability database: восемь указанных М+ подземелий, 248 записей НИП / 1029 связей со способностями. Выберите НИП, способность, набор своей специализации и время предупреждения. Источники и дата снимка включены; неизвестные encounter/timer ID редактируются вручную.
- Специализации выбираются по названиям. Для способностей показываются ID и доступные английские названия, есть кэш. Таблицы HTML/CSV/JSON поддерживают разные классы; реальные нажатия анализируются отдельно от рекомендованных приоритетов.
- Ctrl+A, Ctrl+click, Shift+click, Shift+перетаскивание и групповые Refresh/Delete в Addons. Файлы сохраняются. После запуска Addons и активные логи пусты; профили, заметки, таблицы, бэкапы и сохранённые WCL-ключи остаются.
- Cloud AI синхронизирует варианты с ответом API для личного ключа, обновляет список при смене провайдера/ключа и убирает неподходящие типы моделей.
- Important abilities: ручные отметки, загрузка Method или сохранённого HTML. Семь названий Altar of Fangs из скриншота требуют подтверждения ID. Полные страницы Method в облаке недоступны (HTTP 403); основной выбор НИП/способности от них не зависит.
- Пройдено 82 теста ядра без пропусков с реальным NSR и Lua 5.1, включая декодирование редактированного профиля. Проверен интерфейс создания Guardian-профиля с боссом и трешем, импорт таблиц, экспорт и поиск по исходникам.

NSR для треша использует mapID + spellID через ExBoss; отдельного NPC-фильтра у этого триггера нет. Наличие способности в базе не гарантирует таймер у провайдера. Поведение в игре проверяет пользователь.

Закройте приложение, распакуйте весь ZIP в новую папку и запустите Pztk x Glyalith.exe. Верхняя строка покажет 0.1.10. Подробности — START-HERE.txt, CHANGELOG.md и VALIDATION.md.
