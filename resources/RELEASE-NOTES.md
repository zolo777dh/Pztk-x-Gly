Pztk x Glyalith — standalone Windows x64 desktop prototype.

Download the Windows ZIP, extract the entire folder and launch `Pztk x Glyalith.exe`. Use **Open disposable demo** to try the interface before connecting actual addon folders. Node.js and Python are not needed to run the packaged application.

Includes Lua/dependency diagnostics, BugSack/BugGrabber imports, reviewed patches with verified ZIP backups and rollback, encounter notes, NSRPACK2 reminder export, multi-pull timing statistics, HTML/JSON/CSV reference parsing and explicit column mapping.

The application is unsigned. In-game behavior needs user validation. API coverage is partial; AI requires a separately configured model/provider and Warcraft Logs imports require a session access token. Live credential-backed integrations and native Windows interaction need verification. See README.md and VALIDATION.md for details.
