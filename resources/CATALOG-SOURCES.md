# NPC and dungeon catalog

## Raid catalog (0.3.0)

`raid-catalog.json` reads factual encounter/spell IDs, English names, categories and Heroic/Mythic membership from the user-supplied NorthernSkyRaidTools 12.1.31 BossData.lua and 20 BossTimelines files (Midnight S1/S2). Repeated phases are deduplicated by spell ID while difficulty/phase membership is retained. The 0.3.0 catalog also records literal phase-relative mechanic schedules per difficulty for native NSRT reminder generation. No executable Lua, alert implementation or defensive sets from that addon are bundled. These reference schedules are not observed player defensive presses. The reference is All Rights Reserved; this app uses its own implementation and a factual catalog.

Confirmed timer aliases are taken from the supplied NSR `BOSSMOD_KEY_TO_JOURNAL` and `DBM_TO_BIGWIGS` literals. Source spell IDs used for icons are not proof that every boss mod broadcasts the same timer key. Unaliased entries retain their factual spell ID with an explicit source/verification note. In-game behavior needs the installed NSR/boss-mod events. For NSR, difficulty is a UI catalog filter and shared encounter/spell bindings are exported once. Native NSRT exports use separate Heroic and Mythic alert tables with their own phase schedules.

Reproduce with `node tools/build-raid-catalog.mjs EXTRACTED_NSRT_ROOT NSR_CHECKOUT`. The JSON records per-file SHA256 and metadata/alias-source hashes. Uploaded Lua is parsed as literals, never executed; the source addon itself is not shipped.

## Mythic+ source verification (retained from 0.1.13)

The current snapshot uses the uploaded LittleWigs `Midnight.zip` (SHA256 `e53c7ca925641736451bd9a0cffe582ee506f7226654d6afdef5c78e900b17a0`) for Murder Row, Den of Nalorakk, The Blinding Vale, Voidscar Arena and Altar of Fangs. Those dungeon module bodies match the prior upstream revision after line-ending normalization. The archive does not include Ruby Life Pools, Temple of Sethraliss or Kings' Rest; their modules remain from the pinned upstream LittleWigs checkout below.

Uploaded `EXBossData.zip`, version 1.0.0 (SHA256 `610f39c75ad7a87c4d1f5fa94c17c7e9800ef738573eb585f2e0b697684a8a42`), covers the Mythic+ source contract for all eight maps. Only literal facts from EncounterData.lua, TrashCDData.lua, TrashCDLocale.lua and FixedTimelineBosses.lua are read. Scripts and functions are not executed; Factory.lua and defensive preset packs are not imported. Per-file hashes are retained in the JSON.

There are 249 selectable NPCs and 800 NPC/ability associations. MDT supplies seasonal NPC identities and associations; it is not a complete allowlist of LittleWigs broadcast keys. Known Mythic/Retail branches and reachable callbacks determine numeric LittleWigs Bar/CDBar and message evidence. Legacy Retail overrides replace earlier definitions. CastBar has a different callback from NSR's regular timer bridge and is not counted as cooldown evidence. Same-Day Delivery (474765) is retained from its reachable LittleWigs timer even though MDT omits that key.

Configured EXBoss Mythic+ event IDs are joined to actual spell IDs, excluding the contract's exclusions and events outside its configured trigger rules. Exact spell matches take precedence over duration joins. A unique literal duration in the same Mythic-compatible encounter can establish a separate cross-provider reference; ambiguous durations do not. For example Nalorakk's 13-second branch links LittleWigs 1243569 and EXBoss spell 1297792. This does not rewrite the export to a timeline event ID. The default boss key remains the LittleWigs key; cross-provider references are informational.

EXBoss trash tables use challengeModeID; exported NSR filters use instance mapID. Creature comments/headers and cast references group auras under mechanics, with explicit timer aliases preserved. Spirit of Hunger's Feast of Misery is displayed as cast 1238725 and defaults to EXBoss timer key 1238687 in map 2825. Group encounters are associated through explicit module NPCs, names/filenames, or an unambiguous journal-plus-spell match; multi-creature mechanics are restricted to supported creature associations.

Reproduce the current overlay with `node tools/build-npc-catalog.mjs MDT_CHECKOUT LITTLEWIGS_CHECKOUT EXTRACTED_MIDNIGHT_ROOT MIDNIGHT_SHA256 EXTRACTED_EXBOSSDATA_ROOT EXBOSSDATA_SHA256`. Extracted roots are source inputs, not bundled application code. Sources establish the documented provider snapshot, not live verification of every ability in the user's client. Unknown English labels stay explicit IDs and may be resolved by the tooltip cache.

## Earlier source snapshots

The bundled JSON contains factual NPC names/IDs, NPC-to-spell associations, English spell labels when available, and independently identified dungeonEncounterIDs. It excludes executable addon code, routes, coordinates, maps and textures. No downloaded Lua is executed by the generator or application.

- Mythic Dungeon Tools: https://github.com/Nnoggie/MythicDungeonTools, revision `2a2df3bb28471ec9900942f1856215f85fdefe31`, eight current `Midnight/*.lua` dungeon enemy tables.
- LittleWigs: https://github.com/BigWigsMods/LittleWigs, revision `0463cc620b4da7c4cd1df155fe082f2dc5589ce2`, corresponding Midnight, Dragonflight and BfA modules. `SetEncounterID` is separate from the journal encounter argument of `NewBoss`; explicitly registered NPCs identify multi-creature bosses. Numeric Bar/CDBar calls are evidence in that source snapshot, not a guarantee for another client or installation.
- Raider.IO: https://github.com/RaiderIO/raiderio-addon/blob/master/db/db_dungeons.lua, generated 2026-10-18, season-mn-2. Instance map IDs and Challenge Mode IDs are stored separately in `core/dungeons.mjs`.

Reproduce from those source checkouts with `node tools/build-npc-catalog.mjs /path/to/MythicDungeonTools /path/to/LittleWigs`. JSON includes exact upstream revisions and source filenames. Version 0.1.12 exposes 246 NPC entries and 794 selectable associations across eight dungeons. The original MDT associatedSpellIds are retained as provenance, separate from choices. Main boss mechanics use LittleWigs GetOptions literals under known Mythic/Retail branches, intersected with that NPC's seasonal MDT spell table. Options absent from MDT are excluded rather than inferred from another difficulty. Known duplicate mechanic names are grouped; related effect IDs remain informational. For Zaen, Murder in a Row is selectable once as 1218347; damage/aura variants are not alternate choices. Two creatures without a confirmed selectable intersection are omitted.

The scope is the MDT Midnight seasonal Mythic+ dataset, not pooled Normal/Heroic Encounter Journal IDs. Runtime checks exclude explicit non-challenge difficulty tags and deduplicate IDs per NPC. Shared IDs remain valid when present in the Mythic+ source. The sources do not provide an independently verified difficulty table for every spell; this is source-based verification, not a live Warcraft Logs validation of all 794 entries. Unknown English spell names remain explicit IDs. This is not a complete game database or proof that a cast deserves a defensive.

NSR boss rules use dungeonEncounterID plus timer spell key. ExBoss trash rules use instance map ID plus timer spell key; the current addon does not filter these rules by creature ID. Selection in the catalog cannot create a missing timer. Verify provider and client versions in game.

Method reference URLs are recorded per dungeon. The user-supplied Altar of Fangs screenshot establishes seven important ability/NPC names but no numeric spell IDs. Those rows remain unverified until the user supplies a mapping. The cloud network gateway denied the eight Method pages (HTTP 403); their complete current contents and markup were not validated here. Saved HTML parsing is tested on controlled structural fixtures, never by executing page scripts. No strategy article text is bundled. Local markings are stored outside the application install folder.
